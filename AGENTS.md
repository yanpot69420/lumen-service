# Aturan kerja project

Project ini sudah digunakan di production. Ikuti ketentuan pengguna berikut:

- Sebelum mengubah file, buat branch lokal baru untuk setiap pekerjaan perubahan yang berbeda. Gunakan awalan `codex/` dan nama yang menjelaskan pekerjaan.
- Lanjutkan pekerjaan yang sama pada branch terkait; jangan mengerjakan perubahan langsung pada `master` atau branch production.
- Commit lokal boleh dibuat sesuai pertimbangan agen setelah perubahan siap dan pemeriksaan yang relevan selesai.
- Jangan melakukan push ke GitHub tanpa perintah eksplisit pengguna untuk pekerjaan tersebut.
- Jangan membuat issue di GitHub tanpa perintah eksplisit pengguna.
- Permintaan mengubah aplikasi atau membuat commit saja tidak merupakan izin untuk push atau membuat issue.
